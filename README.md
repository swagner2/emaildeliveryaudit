## 🚀 Deployment

Connected to **Cloudflare Pages**. Any push to `main` auto-deploys within ~30 seconds.

To update the page:
1. Replace image files in `images/` folder on GitHub
2. Or edit `index.html` directly on GitHub
3. Commit → live automatically
